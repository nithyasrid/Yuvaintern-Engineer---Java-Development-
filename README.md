# Java Internship – Complete Weekly Projects

## Overview

This repository contains my complete work from a 6-week Java internship. The internship focused on building a strong foundation in Java programming through practical, task-based implementations.

Each week focused on a specific Java concept, and the concepts were implemented using integrated programs to demonstrate their practical application.

## Technologies Used

- Java
- Object-Oriented Programming
- Data Structures
- Java I/O
- Exception Handling
- Multithreading
- JDBC
- MySQL
- SQL
- Git & GitHub

## Weekly Work

### Week 1 – Java Syntax and Basic Operations

Covered the fundamentals of Java programming, including:

- Basic Java syntax
- Variables and data types
- Operators
- Conditional statements
- Loops
- Arrays
- Type casting
- Strings and String methods
- Methods
- Mathematical operations
- Program execution and lifecycle

The week focused on developing a strong foundation in Java programming.

---

### Week 2 – Object-Oriented Programming

Implemented the core principles of Object-Oriented Programming:

- Classes and Objects
- Attributes and Methods
- Constructors
- Encapsulation
- Inheritance
- Polymorphism
- Abstraction
- Interfaces
- Object lifecycle

An integrated e-commerce-based example was used to demonstrate how OOP concepts work together in a real-world application.

---

### Week 3 – Data Structures in Java

Explored commonly used data structures and their practical applications:

- Arrays
- Linked Lists
- Stacks
- Queues
- HashMap
- TreeMap
- Trees
- Searching and data organization
- Basic time and space complexity

The implementations demonstrate how appropriate data structures can be selected for different application requirements.

---

### Week 4 – Java I/O and Exception Handling

Implemented Java file and exception-handling operations.

Topics covered:

- Java I/O
- Byte Streams
- Character Streams
- Console Input
- File Creation
- File Reading
- File Writing
- File Updating
- File Deletion
- File Copying
- Checked Exceptions
- Unchecked Exceptions
- try-catch
- finally
- throw and throws
- try-with-resources
- Multiple catch
- Chained Exceptions
- Custom Exceptions

An integrated Student File Management System was developed to combine file operations with exception handling.

---

### Week 5 – Multithreading in Java

Studied and implemented concurrent programming concepts in Java.

Topics covered:

- Multithreading
- Thread creation
- Thread class
- Runnable interface
- Thread lifecycle
- start()
- run()
- sleep()
- join()
- Thread priority
- Synchronization
- Race conditions
- Inter-thread communication
- wait()
- notify()
- notifyAll()
- Deadlock
- Thread pools
- ExecutorService

An integrated Concurrent Order Processing System was developed where multiple customer orders are processed concurrently while synchronization protects the shared inventory.

---

### Week 6 – Java Database Connectivity (JDBC)

The final week focused on connecting Java applications with relational databases using JDBC.

Topics covered:

- JDBC architecture
- DriverManager
- Connection
- Statement
- PreparedStatement
- ResultSet
- SQLException
- executeQuery()
- executeUpdate()
- Database connection
- Table creation
- INSERT
- SELECT
- UPDATE
- DELETE
- CRUD operations
- Try-with-resources

An integrated Student Management System was developed using Java and MySQL to demonstrate complete database CRUD operations.
